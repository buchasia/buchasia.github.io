The amount of data that is being generated everyday by every organization has been growing since last few years. There are many roles involved in managing, controlling and using the data. Let us discuss the three roles dealing with data that are common in most organization these days:

- Database Administrator: A Database Administrator is responsible for managing, maintaining, and securing an organization's databases. They are responsible for the integrity of the data. They are also responsible for the performance and implement security measures to protect sensitive information. They work together with developers and IT teams to support business operations.

- Data Engineer: A Data Engineer designs, builds, and maintains data pipelines and architectures that enable the efficient collection, storage, and processing of large datasets. They use SQL, Apache Spark and cloud platforms to ensure that the flow of data is smooth from various sources to the databases and analytical systems. They make sure that the data that the data analysists receive is clean and reliable.

- Data Analyst: A Data Analyst examines and interprets data to uncover insights that help businesses make informed decisions. They create reports and dashboards using tools like Excel, Power BI or Tableau. They help organizations identify trends, measure performance and provide data-driven insights.
